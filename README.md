# CalcDaily

**一个面向考研高数的自适应练习网站。**

[在线体验](https://calcdaily.cn) · [产品需求文档](./docs/PRD.md)

## 关于项目

CalcDaily 是我在准备考研期间开发的个人项目。

考研数学的复习周期很长。做题并不难开始，困难的是持续找到适合自己当前水平的题目，以及在做错之后真正把薄弱知识点补回来。

我希望做一个能根据练习表现不断调整的刷题工具，让学生不用每次都从固定题单里挑选下一道题。

目前 CalcDaily 聚焦高等数学中的**极限、导数和积分**，支持电脑和手机浏览器使用。

## 目前能做什么

- **自适应练习**：根据答题表现、知识点掌握情况和历史记录调整下一道题的难度，也可以选择固定难度练习。
- **能力诊断**：通过简短的诊断题估计初始水平。可以跳过，之后通过日常练习逐渐校准。
- **AI 出题与判题**：接入 DeepSeek 生成练习题，并辅助判断数学表达式的等价性。
- **错题复习**：按知识点组织复习任务，跟踪连续答对情况，而不只是保存一份错题记录。
- **学习分析**：查看各模块能力、薄弱知识点、历史正确率和练习记录。
- **账号同步**：支持游客使用，也可以注册账号，在不同设备间同步学习数据。

练习系统使用简化的 IRT 与 Elo 更新方法估计能力，并结合知识点表现选择后续题目。难度分为 L1–L12，目前仍属于自定义的练习难度体系，并非经过大规模考生数据校准的标准能力量表。

## 关于 AI 的可靠性

这是开发过程中花费时间最多的部分之一。

最早的版本直接让大模型生成题目和答案。实际测试后发现，模型有时会给出错误答案，也可能生成正确但难以自动验证的表达式。单靠调整 Prompt 无法稳定解决这些问题。

因此后来加入了独立的数学验证、生成结果审核和备用题机制。

目前的处理流程大致是：

生成题目 → 检查格式与数学答案 → 审核题目 → 通过后交付；无法确认正确性的题目不会直接展示，而是使用经过验证的备用题。

另外也针对超时、重复请求、预取缓存和错误分类做了多轮修复。

这些措施能减少已知错误，但还不能保证所有 AI 生成题目都正确。数学正确性和出题稳定性仍然是持续测试的重点。

## 技术实现

项目采用原生 HTML、JavaScript、Tailwind CSS 和 MathJax 构建前端。

服务端使用腾讯云 CloudBase，负责账号认证、学习数据同步以及 DeepSeek API 的调用。自适应算法、题目校验、错题队列和学习状态更新由项目代码实现。

主要技术：

- HTML / JavaScript / Tailwind CSS
- MathJax
- Tencent CloudBase
- DeepSeek API
- IRT / Elo-style Ability Estimation
- Mathematical Verification & Automated Testing

项目包含自动化测试。可以使用 `npm test` 运行仓库中的测试集，使用 `npm run check:sync` 检查共享数学引擎文件的一致性。

## 目前进展

CalcDaily 已经上线，主要练习流程、账号系统、学习记录与云同步功能均已实现。

现在的重点是完善可靠性，并邀请真实考研学生试用。我尤其想确认几件事：系统推荐的难度是否合理、错题复习是否真正被使用、学生是否愿意连续使用，以及自适应练习相比固定题单是否具有实际优势。

目前还没有足够的真实用户数据证明它能够提高考试成绩，这也是接下来需要验证的部分。
