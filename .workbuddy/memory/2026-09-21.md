## 病根（两处叠加，各自都足以放行）

1. **`gateDecision()` 只拦 Tier C**：`tier !== C` 一律 VERIFIED —— 而 Tier B 的定义
   就是「读得懂、但这一次数值没给结论」，和 Tier C 一样属于「我们没验证过」。
2. **parser 不认方括号**：`toInfix` 白名单只有 `+-*/^(),`。答案
   `\left[...\right]` 整条 unparseable → `uncertain` → Tier B → 旧闸门放行。
   **幂指函数答案几乎都长这样**，所以这不是偶发。

两道线上错答案（`y=((x²+1)/(x²−1))^(arctan x)`，r1 缺 `arctan x` 因子 / r2 符号写反）
就是这样漏出去的；修复前实测**连正解也是 Tier B**，说明旧闸门**根本没有区分能力**。
